# Roadmap

Phases 0–5 are implemented as an MVP: repository/product contract; nationwide bilingual discovery; accounts and venue self-service; community moderation; transactional check-ins, stamps, XP and passports; promotions and venue-scoped analytics. Phase 6 engineering hardening is implemented with PWA/offline fallback, legal/privacy surfaces, security headers, consent-based coarse location, scannable check-in QR material, a deployment runbook, zero known dependency advisories and expanded browser coverage. External legal, provider-credential and backup-drill gates remain open.

Before commercial launch: obtain professional legal review, complete an operator-led backup restore drill, configure desired phone/Apple/X identity providers, add real authorised venue/event content, and review map hosting capacity once real traffic is measurable. The public map now uses MapLibre with OpenFreeMap by default and supports a custom style URL.

Later options remain native apps, payments/ticketing, AI extraction/translation, rotating QR tokens, social planning, supplier marketplace and additional languages.
